模型、算法与数据来源

抽取模型：每次变换从 18 个词条中不放回抽 3 个（同一词条不会出现两次）。普通词条单格权重 6.5%，三条强化词条分别为 0.833% / 0.833% / 0.834%。抽中后数值在词条区间内等概率，再按评分表换算成分值。

总分：3 个词条分值之和，精度 0.1 分。强化词条分值 = 系数 × 强化等级 × 评分倍率，所以切换 +9～+13 会改变总分分布。

概率：枚举全部 4,896 种词条排列与 4,896,000 种「词条 + 数值」结果后精确求和，没有随机模拟误差。

次数与花费：每次变换相互独立，达成次数 N 服从几何分布：P(N = n) = (1−p)ⁿ⁻¹p，P(N ≤ n) = 1−(1−p)ⁿ，E[N] = 1/p；累计花费 = N × 单次价格。中位数 / 90% / 99% 由分位数公式直接算出。
