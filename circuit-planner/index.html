使用说明

基本规则

  • 四个部位各占 4×4 电路盘中的 1 格（绿色装备格），其余 15 格为电路，共 60 块电路。
  • 部位与位置：左上 上衣、右上 下衣、左下 手套、右下 鞋子；装备格默认位于各自靠中心的一角。
  • 电路类型：I-1 竖线、I-2 横线；L-1 右上、L-2 右下、L-3 左下、L-4 左上；T-1 左下右、T-2 上左下、T-3 左上右、T-4 上右下。
  • 电路必须闭合（所有接口都有对接、没有悬空线头）且联通（整组电路接在装备上）才会通电生效；未通电的电路会变暗，并在右侧「连线警告」中列出。
  • 装备格是电源与导体：任何指向装备格的接口都视为已对接，两块电路也可以借装备格连通。
  • 颜色对所有电路生效：红色=演算、蓝色=循环、绿色=复原。切换后 60 块电路一起变色，电路名称也随之改变。
  • 预设电路：顶栏「预设电路」提供目型电路、毕业电路、C 形电路、H 型电路四种单盘预设，方向 0°/90°/180°/270°；目型转 90° 得横向，毕业电路转 90° 得竖向。套用部位可选全部。
  • 属性：上衣 流血／技能初始化概率；下衣 两极化／强／弱；手套 技能伤害；鞋子 王伤／组队动速。
  • 数值：一般为 0.7 / 0.8 / 0.9 / 1.0，组队动速为 0.5 / 0.6 / 0.7 / 0.8。
  • T 型电路可在数值里选「复制」：复制电路没有固定属性/数值，效果等于所连相邻电路属性的一半（例如相邻三个 1.0 流血 ≈ 1.5 流血）。复制电路彼此相邻会互相拖累，页面会给出提醒。

截图导入

  • 点顶栏「截图导入」，或者直接按 Ctrl+V 把截图粘贴进来（也可以把图片拖进窗口任意位置）。支持整张 2×2 四盘截图，一次导入 4 个部位。
  • 想换一张图：不用关弹窗，直接把新截图再拖进来、或再按一次 Ctrl+V、或点「选择图片」即可覆盖当前这张；换图会清掉之前的手工纠正和滑条调整。
  • 识别原理：霓虹线的中心接近纯白，而底盘是暗红、格子描边是纯红、徽章是绿，所以按「白芯」抠线即可（阈值自动适应，被缩放/重编码变淡的图也能认）；格距用投影自相关求，与图片分辨率无关；再对「装备格锚点 / 线路范围中心 / 图片中心」三种候选各拟合并打分，取接口咬合最好的那个。因此截图被缩放、裁剪、甚至非等比拉伸都能自动对齐。
  • 右侧「自检：n/4 盘完整闭合联通」是关键指标：显示 4/4 ✓ 就说明识别和截图的电路完全一致；不满 4/4 时调「横向缩放 / 纵向缩放 / 左右 / 上下 / 灵敏度」，或者直接在图上拖动、点「复位」回到自动结果，直到变成 4/4。
  • 复制芯片也能识别：芯片右上角有个小「十」字标识（颜色跟随主题，演算红／复原绿／循环蓝），识别结果按「中心横竖都亮、四对角都暗」的加号响应判定，并在预览里画出黄色十字；识别错了可以在图上点那一格、再点「复制芯片：是/否」手工纠正。
  • 导入只决定电路形状（以及是不是复制芯片）：原本已有电路的属性、数值、已有状态都会沿用；截图里没有电路的位置会被清空；新格按勾选（默认「已有」）标记。若勾了「按截图配色切换颜色」，会同时把 60 块电路切到截图对应的演算/循环/复原。
  • 导入后可以 Ctrl+Z 撤销。

操作

  • 看某一块电路：单击它，右侧最上方的「当前电路」卡片会显示完整名称（如 L-1型上衣增幅电路（演算））、部位、属性、数值、已有／未有（用顶部「状态」按钮切换）、通电状态，并可用下拉框直接改类型／属性／数值（T 型可选「复制」）。
  • 鼠标悬停或选中电路格时显示类型与属性；开启工具栏「格上显示属性」后会常显。
  • 选择模式：单击选中（此时上方按钮会切换成这块电路的属性，点一下就是改它）；拖拽框选可跨部位批量；Shift+单击 加选／取消；Ctrl+A 全选；Esc 取消选择。
  • 画笔模式：按住拖拽即可按当前画笔（类型／属性／数值（含复制）／已有状态）连续涂画。
  • 上方工具栏的按钮：有选中时显示的是选中电路的属性，点击即批量套用；没有选中时只改变画笔。
  • 快捷键：1~9/0 切换类型、R 旋转、Delete 清空选中、Ctrl+Z 撤销。
  • 标记为未有的电路会带橙色虚线边框与「缺」角标，并出现在右侧清单中；点清单或警告里的条目会自动选中并高亮对应电路。清单每行右侧有「复制名称」和「复制属性」：前者复制电路名字，后者复制按模板生成的属性描述（n% 替换为数值，无 n% 的追加 +数值）；都不会触发高亮。点行本身仍然高亮定位。
  • 配置会自动保存在浏览器本地；「导出／导入」可保存为 JSON 文件。
